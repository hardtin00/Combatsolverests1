## 安装

1. 关闭游戏。
2. 把 `CombatSolver1.jar` 复制到游戏目录的 `mods/`（保留原 mod 备份）。
3. 在游戏目录建 `cs1-engine/`，把 `s2b0_search_3d.exe` 放进去，文件名保持不变。
4. 用 ModTheSpire 勾选 `combatsolver1` 后启动游戏。
5. 不需要设置任何环境变量，不需要管理员权限。

## 使用

- 战斗内点 `▶ 自动打完这场`：开始连续执行整场战斗；再点一次变 `■ 停止自动`。
- `重新计算` 手动触发一次搜索；`暂停 / 继续` 临时挂起；`清路线` 清空当前路线。
- 面板在非战斗房间自动隐藏。赌博筹码 / 工具箱这类战前选牌屏会在进战斗时自动代选。
- 路线区显示整场所有回合；行数多时点 `▽ 点此翻页` 翻页。
- 面板每 2 秒在 `~/.combatsolver1-isolated/panel-layout.log` 写一行 `diag state=…`，
  可据此判断求解器是否在工作。

## 已知边界

- 仅面向铁甲战士、从地图进入的普通战斗；其他职业与罕见机制未完整验证。
- 结果是预算内找到的路线，不保证数学上的全局最优。
- 详见 `验收清单.md` 末尾「已知边界」。

## 修复要点（§127）

此前有一版 ASM 补丁把 `ifne` 改成 `goto`，破坏 JVM StackMapTable，游戏执行采集方法时抛
`java.lang.VerifyError: Inconsistent stackmap frames`，导致采集层崩溃、引擎从不运行、
面板显示兜底文本、按钮看似无反应。现改为在 `ifne` 前插入 `pop; iconst_1`，控制流与栈图
均不变。真机验证见 `dev-notes/evidence/20261106-r23-*.png`。
