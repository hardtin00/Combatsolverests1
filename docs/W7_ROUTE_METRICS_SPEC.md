# W7 评测维度规格：引擎路线占比 / 重规划次数（非实机，L2 离线定义）

> 任务书 W7 要求「对每项改动评测：胜率变化、平均 HP 损失变化、Oracle 漏优率变化、
> 搜索耗时变化、**引擎路线占比**、**重规划次数**」。前四项已由 W0 两把尺子覆盖；
> 本文件定义后两项的**指标、采集点、当前真实值、统计方法**。
> 本单元**不改运行路径、不编造数据**，属用户划定的「非实机」范围。

## 指标定义

| 指标 | 定义 | 单位 | 真值来源 |
|---|---|---|---|
| 引擎路线占比 | 一场战斗中「实际执行的路线来自外部引擎 sts_lightspeed」的回合数 / 总执行回合数 | 0..1 或 % | `Plan.source`（`engine`/`local`）；`CombatController.enginePlanAvailable()` |
| 重规划次数 | 一场战斗中「因状态变化/失败/逐动作刷新而重新调用 `CombatSearch.begin` 或重新请求引擎计划」的次数 | 次 | `CombatController.searchAttempts`（本场搜索重试）+ 逐动作重规划事件 |

## 当前真实值（本会话核验，如实）

- **离线 `BatchPlay` 200 局**：恒 `Plan.source="local"`（纯 `CombatSearch` → 同 `CombatEngine` 重放），
  **引擎路线占比 = 0**、**重规划次数 = 0**（一次搜索整场计划，不逐动作重规划）。
  这不是缺陷，是离线口径的固有属性；**不得拿它当 W7 引擎主力化的成效数字**。
- **真机 L4**：尚未做任何一场战斗（用户接管实机），因此**没有**真实的引擎路线占比 /
  重规划次数样本。任何非零数字都属编造，本文件不填。
- `CombatController` 已有 `searchAttempts`（本场搜索重试计数，453 行 `search.begin` 处递增），
  但它统计的是「本地 beam 重试」，**不等于**「逐动作重规划」；W7 第 6 项（每动作后重规划）
  尚未实现，重规划事件的采集点也尚未埋点。

## 采集点（W7 主力化实现时需埋点）

1. **路线来源事件**：每次 `PlanDeployer.execute(...)` 开始时记录
   `{"event":"route_source","source": plan.source, "turn": liveTurn, "battle_id": ...}`。
   `Plan.source` 已在 `EngineBridge:302` / `CombatController:794,874` 设为 `engine`，
   在 `CombatController:328` 设为 `local`。
2. **重规划事件**：每次因状态变化重新搜索/请求引擎计划时记录
   `{"event":"replan","reason": "...", "turn": ..., "action_index": ...}`。
   现有 `search.begin` 在 `CombatController:453`（本地重搜）可作为其中一个来源；
   逐动作重规划（W7 第 6 项）实现后新增独立埋点，二者分别计数、不混用。
3. **统计口径**：按 `battle_id` 分组，`engine` 回合数 / 总回合数 = 占比；
   `replan` 事件计数 = 重规划次数。失败/中止的战斗单独标注，不计入分母。

## 与其他 W0 指标的关系（任务书要求逐项对照）

W7 每项改动交付时必须同时给出：
- 胜率变化（BatchPlay 200 局，同模拟器自打口径，前后同种子同预算）
- 平均 HP 损失变化（同上）
- Oracle 漏优率变化（Q1-42 PROVABLE / W8 Q43-45，前后同题库）
- 搜索耗时变化（平均/最大，注意 JVM 抖动，需多次复跑取同量级）
- **引擎路线占比 / 重规划次数**：离线阶段恒 0/0，需在 W7 主力化 + 真机 L4 后才有非零值
- 禁止仅因「搜索次数增加」就宣称质量提高（任务书明文）

## 离线可验证部分（本单元）

`tools/solvertest/RouteMetricsParseCheck.java`：给定一份合成事件流，验证
「按 battle_id 分组统计 engine 占比 / replan 次数」的解析逻辑正确（纯字符串处理，
不依赖游戏对象）。**合成流不是真机记录**，仅证明统计器实现无误。

## 限制（如实）

- 本文件是**规格与骨架**，不是 W7 主力化实现；引擎 worker 常驻、每场重导 RNG、
  逐动作重规划、高预算 ≥20000 次模拟均**未完成**。
- 引擎路线占比 / 重规划次数的**真实数值**需用户实机 L4 后才有；本文件不填数字、不编造。
- L2 离线（定义 + 解析自检），非 L4。
