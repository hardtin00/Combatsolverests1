# W8 Q44（异蛇之油）漏优的具体对局与根因

> **★ 2026-11-06 更正（见 `docs/W8_Q44_WIDTH_GRADIENT.txt`）**：本文件第 34/36/45 行
> 「不是宽度 / 是评分或动作生成层面」的结论**已被实测推翻**。用更宽的
> `within=96/beam=64`（以及 128/96）时 Q44 **不漏优**，beam 第 1 回合打出与穷举参照
> 一致的 5 张牌。真实根因是**默认 `withinTurnWidth=32` 太窄**，不是动作生成缺失。
> 下方原分析保留作历史记录，不再作为结论引用（AGENTS.md 3.C / 7）。

```bash
java -cp build/solvertest SearchQuality --verbose --only 44-44
```

## 具体差异

| | 参照（穷举最优） | beam（当前搜索） |
|---|---|---|
| 回合数 | 1 回合结束 | 2 回合 |
| 第1回合动作 | 喝油 → **Cleave** → Strike_R → Anger → Defend_R（5 张） | 喝油 → **Heavy Blade** → Anger → Defend_R（4 张） |
| 第1回合末 HP | 无损（60/60） | 56/60（-4） |
| 终局分 | `999970` | `995970` |

## 根因（有三组受控实验支撑）

1. **不是宽度**：W8-b 的 `--sweep --only 43-45` 覆盖 49 组 `(within,beam)`，Q44 **没有一组不漏优**。
2. **不是排序先验**：W8-b 的 `PriorOracle 43-45`（先验开启）下 Q44 的 PROVABLE beam 仍是 `995970`，不变。
3. **是评分/动作生成层面**：`turnScore` 对「喝油后抽到的低费/0 费牌组合」估值不足——
   参照用 `Cleave + Strike_R + Anger + Defend_R` 四张低费牌铺满一回合，beam 却把 2 费
   `Heavy Blade` 排到前面、少打一张、多吃 4 点伤害。引擎里 `Snecko Oil` 只建模为「抽 5」
   （`PotionLibrary.putExtra("Snecko Oil", 0, 5, 0)`，费用随机化未建模），搜索没有把
   「喝油后手牌结构变化 → 低费牌连打」的组合价值反映进排序分，导致含油路线被剪掉。

## 结论（如实）

- 当前本实现在 Q44 **也做不对**，故**没有**「参考实现会做错、本实现做对」的证据，**反超未成立**。
- 后续修复方向：在评分/动作生成层补「药水后手牌低费组合价值」（P1），或在
  `turnScore` 增加与「已打牌数 / 剩余能量」相关的引导项；改 `turnScore` 会动 W0 全局指标，
  需单独单元做 W0 前后对照（与 W7-b 先验接入同规格）。
- 证据等级：**L2 离线**（同一模拟器内 beam vs 可穷举参照），不是真机 L4，不与参考实现实机对跑。
